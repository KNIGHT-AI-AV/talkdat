# Save a copy of your History

Open **Tools > History > Export and manage**. Choose a format and select
**Save a copy**. Saving runs in the background, so you can keep reading, copying
or using another page. The saved-file receipt appears when the file is complete.
Choose **Open** to read it or **Show folder** to find it on this computer.

Text and Markdown include up to the most recent 20,000 saved entries, in saved
order. Search and the Pinned view do not change this export. A receipt explains
when the limit applies. Blank entries are skipped; original paragraph spacing
and multilingual text are kept. An unreadable date is labelled **Date unavailable**
and its readable text remains in the file. **Copy matching entries** follows
your current History search instead.

**Latest entry as PDF** uses the most recent nonblank saved entry. Choose
Boardroom, Modern or Minimal for its report design. To edit a document before
saving it, use **Writing > Ramble**.

**Subtitle draft (estimated)** produces a UTF-8 SRT file with sequential cues
starting at zero. Each cue has up to two lines, wrapped without splitting joined
emoji or combining characters. Timing is estimated from the text. History has
no word-to-audio alignment, so align the draft to your recording before use.
This option uses the same 20,000-entry limit.

Repeated saves create separate files, including saves made in the same second.
A failed save keeps earlier exports and shows an error so you can retry.
Only one History export runs at a time. Clearing text waits until that export
finishes reading and saving.

The latest receipt is shown first. **Show previous documents** reveals earlier
receipts, up to 12 from this app session. The files stay in Talk DAT's local
exports folder after those receipts expire or the app closes. If you move or
remove a file, its old receipt explains that it is no longer available.

The native fallback uses the same complete-file publication and estimated SRT
format. Its older export menu opens the destination folder after saving.
