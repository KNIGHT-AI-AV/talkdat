# Clear local data

Open Settings > Clear local data, or use the same action in Privacy or Tools.
Choose the categories to clear, then select **Preview selected items**. The
preview lists the categories, selected local files and their current size.
Nothing is erased by opening or cancelling a preview.

App settings and onboarding are initially selected. Personal writing, saved
recordings, downloaded models and sign-in are separate choices and start
unselected. Clearing app settings also removes saved provider keys. The
category description discloses this before you continue.

The choices cover settings, onboarding, custom words and translation glossary,
snippets, history, scratchpad, protected voice sessions, Scribe recordings and
notes, app preferences and learned style, exports inside the app folder,
installed plugin files, downloaded speech models, and sign-in. Choose only the
items you intend to remove. Presets refer to these listed categories.

Deleting personal items, models or sign-in requires typing **ERASE** in the
shared interface. A preview expires after five minutes. If selected files or
settings change, preview them again. Linked folders and unexpected file types
are refused. Very large directories can exceed the bounded preview scan.

Finish recording, exports, downloads and other open tools before confirming.
Talk DAT pauses while it closes background audio and plugin hosts. Once an
erase is confirmed, keep the app open until the result appears. New shortcuts
and settings changes are held during this step. The result shows completed
deletions and any items that could not be removed. **Close Talk DAT** exits
without saving the old settings back over the cleared choices.

Unselected categories are kept. External exports, copies, backups, unlisted
application logs, server records and models managed outside Talk DAT are not
part of this operation. Resetting sign-in does not cancel a subscription or
delete a server account. This is selective local deletion, not secure disk
erasure. The reported byte count is the logical size of files removed; it is
not a measurement of reclaimed physical disk space.

If the shared renderer is unavailable, the desktop fallback uses the same
reset execution and shutdown safeguards. Final installer acceptance remains
separate from the source and native-renderer checks recorded in CODEX_LOG.
