# The Pill menu

Right-click the Pill to open a narrow menu centered above it. Near the top edge of the screen, the menu opens below the Pill so its actions stay visible.

Settings, Paste last transcript, History, Tools and Stats stay in your saved order. Speech shows the active speech route; Formatting shows the current writing style. App controls contains updates, restart, quit, menu arrangement and Help.

Tools and other groups replace the menu contents in the same column. Use Back or Escape to return. Escape at the main menu closes it. On shorter screens, Previous and Next show the remaining actions without scrolling.

An unsuccessful action keeps its explanation visible. Settings opens in its own window and restores if minimized. Menu movement follows your reduced-motion setting.

Theme enhancements are bundled image files. Upscaling is done when preparing the release, never while dictating or opening the menu.
