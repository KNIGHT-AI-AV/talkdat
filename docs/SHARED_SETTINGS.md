# The new desktop settings

This guide describes the shared desktop interface being prepared for the next
release. The floating Pill and your existing dictation tools stay familiar.

Use Find a setting to search across the pages. Settings show a draft as you edit;
Save changes applies it, and Discard returns to the saved values. Moving to
another page keeps your draft. If another window changes a setting, review the
latest value beside your draft before choosing which to save. Closing, restarting
or quitting gives you a chance to keep unfinished changes.

On Dictation, select a microphone or follow the system default. Refresh the list
after connecting a device. Preview the start and stop sounds before saving.
For a shortcut, choose Record, hold the keys together, then release. Escape
cancels recording. Add alternative keeps another way to trigger the same action.
Mouse and controller buttons have their own selector. Panic remains available
while assigning a shortcut.
On a Mac, Use Fn / Globe assigns the Mac's dedicated dictation key directly.
That key does not reliably reach a web window's shortcut recorder.

The Pill menu keeps occasional tools under Features. Hover briefly to open it,
click to keep it open, or use the right arrow from its row. Escape returns to
the main menu and restores focus. Arrange menu moves daily actions up and down;
update, restart and close stay together at the bottom. Those changes also wait
for Save changes.

Appearance offers the existing 80 light and dark palettes. The interface honors
reduced motion and system high contrast. Speech provides the downloaded-model
manager and the dated model guide. Research entries in the guide are information,
not selectable models. Removing a download requires confirmation and cannot
run during an active dictation.

Provider keys remain hidden after saving. Enter a replacement to change a key,
or use Remove saved key and then save. Choosing another formatter provider uses
that provider's saved key. Existing account and paid-access tools stay available.
History, Scratchpad, Words & Phrases, Translate and the other tools keep their
established workspaces.
